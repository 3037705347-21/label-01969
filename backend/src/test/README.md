## 1. 用户模块测试 (UserServiceTest)

### 测试场景

#### 1.1 用户登录
- ✅ **登录成功**：用户名密码正确，账号状态正常
- ✅ **用户不存在**：用户名错误抛出异常
- ✅ **密码错误**：密码不匹配抛出异常
- ✅ **账号禁用**：状态为0时禁止登录
- ✅ **黑名单用户**：状态为2时禁止登录

#### 1.2 用户注册
- ✅ **注册成功**：用户名和手机号未被占用
- ✅ **用户名已存在**：重复用户名抛出异常
- ✅ **手机号已注册**：重复手机号抛出异常

#### 1.3 用户信息管理
- ✅ **获取当前用户信息**：正确转换为VO对象
- ✅ **更新用户信息成功**：有权限用户正常更新
- ✅ **更新用户信息-用户不存在**：抛出异常

### 技术要点
- 使用 `MockedStatic` 模拟 `UserContext` 静态方法
- 使用 MD5 加密验证密码逻辑
- 验证异常消息的正确性

## 📦 环境配置指南

### macOS 环境配置

如果遇到 `command not found: mvn` 或 `command not found: java`，请执行以下步骤：

```bash
# 1. 安装 Homebrew（如果没有）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. 安装 JDK 17
brew install openjdk@17

# 3. 配置环境变量
echo 'export PATH="/usr/local/opt/openjdk@17/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# 4. 安装 Maven
brew install maven

# 5. 验证安装
java -version
mvn -version
```

### 使用 IDEA 运行（推荐）

如果不想配置环境，直接在 IntelliJ IDEA 中运行：
1. 打开测试类（如 UserServiceTest.java）
2. 右键点击类名或测试方法
3. 选择 **Run 'UserServiceTest'**

## 测试运行方式

```bash
# 运行所有测试
mvn test

# 运行单个测试类
mvn test -Dtest=UserServiceTest

# 运行单个测试方法
mvn test -Dtest=UserServiceTest#testLogin_Success

# 生成测试覆盖率报告
mvn test jacoco:report
```

## 测试最佳实践

1. **每个测试方法只测一个场景**：遵循单一职责原则
2. **Given-When-Then模式**：清晰的测试结构
3. **独立测试**：测试之间不互相依赖
4. **完整覆盖**：正常流程 + 异常流程 + 边界条件
5. **Mock外部依赖**：只测服务层逻辑，不连数据库
