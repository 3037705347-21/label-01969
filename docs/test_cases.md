# 宠物领养系统 - 核心功能测试用例

## 1. 测试概述

### 1.1 测试范围
本文档涵盖宠物领养系统的核心功能测试用例，包括：
- 用户模块（注册、登录、认证）
- 宠物模块（发布、管理、查询）
- 领养申请模块（申请、审核流程）
- 后续跟进模块
- 黑名单模块
- 消息模块
- 知识库模块

### 1.2 测试环境
- 后端：Spring Boot 3.2.0
- 数据库：MySQL 8.0
- 前端：Vue 3 + Element Plus
