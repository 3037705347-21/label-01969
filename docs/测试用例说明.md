## 运行测试方法

```bash
cd backend

# 运行所有测试
mvn test

# 运行单个测试类
mvn test -Dtest=UserServiceTest

# 运行单个测试方法
mvn test -Dtest=UserServiceTest#testLogin_Success

# 生成测试覆盖率报告（需要添加jacoco插件）
mvn jacoco:report
```

## 测试数据说明

测试基类 `BaseTest.java` 提供了三种预设的用户上下文：
- 管理员 (ID: 1, Role: 1)
- 救助方 (ID: 2, Role: 2)
- 领养人 (ID: 3, Role: 3)

所有测试创建的数据会在 `@AfterEach` 方法中自动清理，避免测试数据污染。
